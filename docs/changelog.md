# Changelog

## [Unreleased]

- 2026-07-31 — [#1](https://github.com/rustycoopes/top-trumps-game/issues/1) Slice 0 — NSD and platform spike: confirmed no runtime permission prompt for NSD discovery on Android 13/14, no `MulticastLock` needed, auto-rename format (`"<name> (2)"`), and `resolveService` concurrency behaviour. Local Network Protection (API 36) remains untested pending hardware. See [slice-0-nsd-platform-spike.md § Delivered](features/top-trumps-core-game/WBS/slice-0-nsd-platform-spike.md#delivered).
- 2026-07-31 — [#2](https://github.com/rustycoopes/top-trumps-game/issues/2) Slice 1 — Walking skeleton: stood up the six-module structure, structurally-redacted `PlayerView`/`OpponentCardView` types, a synchronous `RulesEngine`, deck manifest loading through `DeckSource`, a `MatchSession` (host + guest) over `LoopbackTransport` round-tripping a real JSON codec, a trivial AI opponent, and an ugly Compose screen — one round of Top Trumps played solo, end to end, verified on a physical device. See [slice-1-walking-skeleton.md § Delivered](features/top-trumps-core-game/WBS/slice-1-walking-skeleton.md#delivered).
- 2026-07-31 — [#3](https://github.com/rustycoopes/top-trumps-game/issues/3) Slice 2 — Complete solo match: the full fifteen-round loop with strict turn alternation, interactive tiebreak recursion, the `CHOOSER_WINS`/`DEFENDER_WINS`/`EACH_KEEPS_OWN` all-metrics-tie fallback, win piles, a live score/round counter, a browsable win-pile UI that preserves round state, a victory/defeat result screen with rematch, and a deck-relative AI opponent — verified end to end on a physical device. See [slice-2-complete-solo-match.md § Delivered](features/top-trumps-core-game/WBS/slice-2-complete-solo-match.md#delivered).
- 2026-07-31 — [#4](https://github.com/rustycoopes/top-trumps-game/issues/4) Slice 3 — The real Motorcycles deck: thirty real, sourced-and-cited motorcycles (1923–2018) with Wikimedia Commons CC-licensed photographs, a documented weight/top-speed/length convention for cards where published figures disagree or don't exist, tightened deck manifest validation, a deck picker, and Coil-based card/win-pile image rendering with an "Age — N years" display and win-direction indicators — verified end to end on a physical device. See [slice-3-motorcycles-deck.md § Delivered](features/top-trumps-core-game/WBS/slice-3-motorcycles-deck.md#delivered).
- 2026-07-31 — [#5](https://github.com/rustycoopes/top-trumps-game/issues/5) Slice 4 — Discovery, lobby and invitations: zero-resolve mDNS peer discovery with TTL-pruned self-filtering, a pure tap-to-invite/accept/decline state machine with a receive-side mutual-invitation UUID tiebreak and `BUSY` handling, a real length-prefixed `TcpTransport` over Wi-Fi-network-bound socket factories, an `NsdManager`/`ConnectivityManager` wrapper in `:platform:net`, and Compose UI for name entry, lobby, settings and a manual connect-by-address fallback — no game yet, the success condition is a connected socket and a screen that says so. Single-device on-hardware smoke-tested (name entry, empty-lobby hint, manual-connect address display, no runtime permission prompt, no regression to solo mode); two-device scenarios (discovery, invite/accept, the tiebreak, `BUSY`, TTL removal, no-internet Wi-Fi) remain to be verified on a second phone. See [slice-4-discovery-lobby.md § Delivered](features/top-trumps-core-game/WBS/slice-4-discovery-lobby.md#delivered).
- 2026-08-01 — [#6](https://github.com/rustycoopes/top-trumps-game/issues/6) Slice 5 — Two-device match: the real `GuestToHost`/`HostToGuest` wire protocol (guest thin-client property enforced by the type system), the protocol-version and deck-hash handshake gates, `HostMatchSession`/`GuestMatchSession` sending a real dealt hand and view stream over the same path solo mode already uses, and a `MatchController`/`TwoDeviceMatchScreen` driving the whole flow in `:app`. Fixed a critical `LobbyController`/`MatchController` transport-listener race and two crash-on-disconnect/malformed-frame bugs found in code review. Resolved the rematch-host-continuity open question (host stays host); two-device rematch itself is deferred to a follow-up issue. No physical device was available to verify the on-device acceptance criteria this session. See [slice-5-two-device-match.md § Delivered](features/top-trumps-core-game/WBS/slice-5-two-device-match.md#delivered).
- 2026-08-01 — [#7](https://github.com/rustycoopes/top-trumps-game/issues/7) Slice 6 — Resilience: a `connectedDevice` foreground service for match duration, a 2s/3-miss (~6s) application heartbeat, a 60s reconnect countdown, full-state resync with sequence-number dedup so a choice in flight during a drop is applied exactly once, direct-redial-then-NSD-fallback reconnection with no new wire field, deliberate-quit-vs-crash distinction, and keep-screen-on scoped to the match screen. Code review (run in parallel by `code-review-master` and `code-quality-guardian`) found and fixed a critical bug where an Activity recreation mid-match silently killed it (no orientation lock anywhere), plus transport/coroutine leaks on reconnect, a courtesy-message flush race, a cross-thread data race, and a double-`leave()` crash. No physical device was available to verify the on-device acceptance criteria this session. See [slice-6-resilience.md § Delivered](features/top-trumps-core-game/WBS/slice-6-resilience.md#delivered).
- 2026-08-01 — [#8](https://github.com/rustycoopes/top-trumps-game/issues/8) Slice 7 — Polish: a Compose `stabilityConfigurationFile` for `:core:rules`/`:core:session` (verified via before/after compiler metrics — every match-screen composable taking a session/view type flipped `unstable` → `stable`), a card-flip reveal with correct perspective and no mirrored back face, a slide-to-pile animation, a two-signal `AnimationGate` that hard-cuts on a two-device resync or after backgrounding without misfiring on live play, six SoundPool-based sound effects (placeholder audio) with a persisted mute toggle, and edge-to-edge inset handling centralized on the `NavHost`. Also finally wired up slice 6's `resync` wire flag via a new `MatchSession.lastResync`. Code review (run in parallel by `code-review-master` and `code-quality-guardian`) found and fixed a critical DataStore collision that would have crashed every launch, a lifecycle-latch bug that could permanently suppress live animations, two sequential-instead-of-concurrent/leaked slide-animation bugs, and a per-frame recomposition mistake in the slide overlay. No physical device was available to verify the on-device acceptance criteria this session. See [slice-7-polish.md § Delivered](features/top-trumps-core-game/WBS/slice-7-polish.md#delivered).
